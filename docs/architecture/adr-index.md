# Webshop architecture decisions

These are the Architecture Decision Records (ADRs) of the Webshop, an imaginary webshop
whose C4 model evolves through these decisions. Each ADR records one decision in
[MADR](https://adr.github.io/madr/) format: the context, the options we considered, what
we decided and what it costs us. ADRs are never deleted: when a decision changes, a new
ADR supersedes the old one.

- **The diagrams**: the C4 views of the model that these decisions shape are on the
  [Structurizr site](https://letscodehu.github.io/c4-adr/).
- **The repository**: [letscodehu/c4-adr](https://github.com/letscodehu/c4-adr), where
  every decision arrives in a pull request together with its model change.

Pick a decision from the menu, or search for one (for example, "RabbitMQ").
